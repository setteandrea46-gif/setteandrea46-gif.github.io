ARCHIVIO PERSONALE

Conservare le fotografie senza perderle.

Il download è soltanto il primo passo. Una raccolta importante merita un archivio ordinato e più di una copia, così un guasto o un cambio di telefono non cancelleranno i ricordi.

La regola delle copie

Un file presente soltanto sul telefono è vulnerabile a smarrimento, rottura e cancellazione accidentale. Dopo aver scaricato le fotografie, crea almeno una seconda copia. Una soluzione semplice è conservarle sul computer e su un disco esterno; in alternativa puoi affiancare un servizio cloud personale.

Per le raccolte davvero importanti è utile seguire la regola 3‑2‑1: tre copie complessive, su due tipi di supporto differenti, con una copia conservata in un luogo diverso.

Cartelle e nomi comprensibili

Crea una cartella con anno, data e nome dell’evento, per esempio “2026-07-30 Matrimonio Anna e Luca”. Mantieni insieme i file originali e non rinominarli tutti nello stesso modo: i nomi assegnati dallo studio aiutano a distinguere le immagini ed evitare duplicati.

Se desideri preparare una selezione per la condivisione, crea una sottocartella separata. In questo modo gli originali restano intatti.

Telefono, computer e cloud

Il telefono è comodo per rivedere e mostrare le immagini, ma non è l’archivio più sicuro. Trasferisci periodicamente i file su un computer o su un supporto dedicato. Se usi il cloud, controlla che la sincronizzazione sia completata prima di eliminare qualunque fotografia dal dispositivo.

Controlla davvero il backup.

Apri alcune immagini dalla copia appena creata. Vedere il nome della cartella non basta: un trasferimento interrotto può lasciare file incompleti.

Qualità per stampa e album

Per la stampa usa sempre il file scaricato dalla galleria, non uno screenshot e non una copia ricevuta tramite chat. Le applicazioni di messaggistica possono ridurre dimensioni e qualità. Conservare l’originale permette di realizzare in futuro stampe più grandi, album o nuove selezioni.

Controlli periodici

Una o due volte l’anno verifica che il disco esterno funzioni e che l’account cloud sia ancora accessibile. I supporti non durano per sempre: quando cambi computer o disco, trasferisci anche l’archivio fotografico e controlla alcuni file a campione.

La galleria dello studio può restare disponibile per un periodo concordato, ma non sostituisce il backup personale. Se manca un’immagine o un file non si apre, avvisa lo studio prima della scadenza comunicata.
