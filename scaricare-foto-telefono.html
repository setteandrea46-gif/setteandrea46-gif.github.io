GUIDA PER SMARTPHONE

Come scaricare le fotografie sul telefono.

Ogni scheda della galleria contiene una freccia e la scritta “Scarica la tua foto”. Il comando salva l’originale ad alta qualità, non la piccola anteprima mostrata nella pagina.

Prima di iniziare

Apri il collegamento ricevuto dal fotografo usando un browser aggiornato. Controlla di avere spazio libero sul dispositivo e, se la raccolta contiene molti file, preferisci una rete Wi‑Fi stabile. Le immagini ad alta qualità possono occupare diversi megabyte ciascuna.

Su iPhone

  1. Scorri la galleria fino alla fotografia desiderata.
  2. Premi la freccia accanto a “Scarica la tua foto”.
  3. Safari può mostrare una richiesta di conferma: scegli di scaricare il file.
  4. Apri l’icona dei download nella barra di Safari oppure l’app File.
  5. Nell’app File controlla la cartella Download, dentro iCloud Drive o “Su iPhone”.

Se vuoi vedere l’immagine direttamente nell’app Foto, apri il file scaricato, usa il pulsante di condivisione e scegli “Salva immagine”. Il nome dei comandi può cambiare leggermente in base alla versione di iOS.

Su Android

  1. Apri il link con Chrome o con il browser del telefono.
  2. Premi il pulsante di download sotto la fotografia.
  3. Conferma il salvataggio se il browser lo richiede.
  4. Apri l’app File, Archivio o Gestione file.
  5. Cerca la cartella Download; spesso l’immagine compare anche nella galleria del telefono.

Se non trovi il file

Controlla l’elenco dei download del browser e verifica che il salvataggio sia terminato. Se il telefono ha poco spazio, libera memoria e riprova. Alcuni browser aperti dentro WhatsApp o altri social gestiscono i file in modo diverso: in quel caso usa il menu del browser e scegli “Apri in Safari” o “Apri in Chrome”.

Qualità della fotografia

La pagina usa una copia leggera per essere veloce; il download richiama invece il file originale caricato dal fotografo. Non fare uno screenshot dell’anteprima se vuoi stampare o archiviare l’immagine.

Download e privacy

Scarica soltanto le fotografie che sei autorizzato a ricevere e non inoltrare il link dell’evento senza il consenso delle persone interessate. Per chiedere la rimozione di un’immagine, contatta direttamente lo studio indicando l’evento.
